## 3 分钟完整路径

1. **开场页**：打开根地址先看到全屏开场页：三行标题、右侧无边框塞莎特计算机 / AI 主题线稿、四组数据快照与「进入系统」；点按钮或按回车直接进入选题工坊。刷新 `#/workshop` 等直达地址不会再播开场，方便演示中途刷新。
2. **选题工坊** `#/workshop`：看 536 个方向、552 个数据集、18,296 位可浏览学者与 2,547 所院校的快照；在方向框输入「医学图像」，用 `↑` / `↓` 高亮联想项、`Enter` 选中，确认后原地进入识别；也可切换「标签组合」「全部方向」两种入口。
3. **选题工坊**：先输入「12」点识别，看页面如何清空旧结果并提示输入不像研究方向；再输入一个不在方向库里的说法（例如「水下医学影像分析」），看识别页如何说明「未命中方向库」、覆盖 536 个方向，并列出相邻方向；用「全库数据生成」兜底，验证候选仍生成，但导师 / 期刊 / 证据标明为全库范围。输入库内说法时，对比识别页给出的方向、大类、匹配词与应用场景；再试「标签组合」与「目录浏览」两种入口：目录先选大类，再按强 / 中 / 弱关联挑小方向，识别条标注「目录选择」。
4. **结果与保存**：确认方向后观察候选数量随方向变化（12–22 条）；在候选卡右下角逐条「+ 加入」，页面不会跳走，标题旁累计「已加入 N 个」，可连续加入多条；从左侧「研究计划」进入 `#/plan`，先看概览（待办完成度、距截止天数、下一步建议）与倒推阶段，再设置截止日期与投入，确认阶段日期与里程碑状态同步变化；点顶部「返回候选继续添加」回到同一份候选；点「调整方向」回到确认页，确认输入、方向与应用场景都还在；改选相邻方向或增减场景后再生成一次。
5. **素材库** `#/materials`：看顶部数据规模、方向—数据集—指标—基线关系条；按大类筛选，点开方向查看数据集、指标、基线与代表论文，再用「在选题工坊使用」回到该方向。
6. **导师与院校** `#/advisors`：默认显示全部去重学者；用平铺 / 列表切换和「加载更多」浏览，按地区筛选（如「美国」「北京」；地区按院校所在机构库归档）。搜索一位学者（例如 `Zisserman`）打开详情：看院校所在地区、ORCID 核验后的任职机构、ROR 链接、2021–2026 发表活跃度与近期论文；再点「在论文库查看这位学者」。再搜索 `Yuanqing Xia`，对比非方向学者的「ORCID 已匹配」详情：同样有 6 年活跃度、3 篇近期论文与 ORCID 主页，但会注明任职范围、论文库只收录推荐学者作品，因此没有论文库按钮。没有个人主页时不会出现搜索引擎跳转；未覆盖 ORCID 快照的学者会明确标注原因。再切到「院校」页签：搜索「中国科学技术大学」，点进学校查看该校全部导师，用「返回院校列表」保留刚才的搜索与地区筛选。
7. **论文库** `#/papers`：从学者详情进入时自动按学者筛选；清空筛选后按年份、类型、领域筛选，搜索题目或 DOI，用「再加载」翻页，点标题跳 DOI / ORCID 记录。
8. **期刊会议** `#/venues`：默认在「按方向推荐」页签内输入方向（如「红外小目标检测」）并点「推荐 venue」，无需回到工坊；切到「全部 701 个」后按 CCF 等级、类型、领域筛选；两个页签都可切换平铺 / 列表，列表适合快速扫名称与领域。点任意一张卡片即可打开详情，查看定位说明、CCF 2026 等级含义、推荐逻辑，以及官网与「在论文库搜索」入口；行尾「官网」仍可直接外跳。
9. **科研方法论** `#/methods`：展开 7 套方法之一；在提示词工作台勾选已完成的科研准备（如已读 3 篇近邻工作、已确认算力），选择研究阶段并填写约束（如「只有一张 4090，数据需审批」），看准备度从 `/8` 变化、待补项被写入提示词，再复制完整提示词。
10. **关于与数据范围** `#/about`：说明数据日期、ORCID / ROR 来源、论文库覆盖与 Web 版限制。
11. **手机端**：用 390px 宽打开同一链接，先看到只保留三行标题与「进入系统」按钮的开场页，点按钮或轻触屏幕进入工坊；点一条候选，确认详情自动出现在候选列表上方，且顶部栏没有遮住标题；打开导师详情确认是底部抽屉；进入期刊页确认方向搜索与列表切换可用且无横向溢出；再从底部导航进入「论文」与「计划」，确认 6 项导航不挤出屏幕；顶栏只保留时钟与主题切换，主题按钮可正常切换。

## 演示时不要说过头

- 方向识别只做**字符串匹配**：覆盖 536 个方向名、术语与关键词，并叠加人工整理的应用场景映射；不是语义向量检索，也不是文献查新；识别页会直接写明这一点。
- 候选的「相关 / 新颖 / 可行」是结构性估计，**不是**文献查新结论；三维度条的中位数与排名只在当次 12–22 条候选内部比较。
- 推荐数据集来自公开基准的整理，是否适合具体题目仍需读原论文确认；无官方链接的数据集会如实标注。
- 素材库的 552 个数据集全部附官方主页，其中 401 个另附可核对的来源或代表论文链接，72 个只记录了论文标题（不提供猜出来的链接），79 个只有官方页面，详情页会写明「该条目以官方数据集页为准；未检索到可核对的单独论文」。所有胶囊数字都是当前筛选池中的数据集数量，不是方向数或标签数。
- 输入「12」不联想、不识别是有意设计：至少要 2 个有效字符且包含汉字或字母；无效输入会先清空旧结果，避免把上一次的候选误当成这次的结果。
- Web 学者目录显示 18,296 位去重学者；其中 941 位有 CSRankings / ORCID 核验的个人主页，13,247 位有院校官网。对 9,774 个 ORCID 标识（9,730 个有公开快照）做了公开记录离线快照：8,602 位姓名匹配，5,322 位有公开作品，923 位的详情可给出 ORCID 公开主页。其中 1,215 位是方向推荐学者，665 位按当前任职核验了机构，481 位修正了机构（例如 Andrew Zisserman 由上海交通大学修正为 University of Oxford）；其余 7,387 位是目录内新增匹配，只补充活跃度、近期作品与任职范围，不改动机构与论文库归属。
- 同名保护：484 个 ORCID 的公开姓名与目录不一致，19 个只做到弱匹配；另有 625 个目录学者的公开任职记录全部在海外，与目录中的中国院校冲突（例如 Shandong University 的 Ling Sun 与 ANU 天体物理学者同名），这些记录都不自动合并，详情页会写明原因。匹配到但公开记录没有任职信息的 4,812 位会标为「仅姓名与作品匹配」，2,575 位的公开记录包含中国院校任职，但仍建议以 ORCID 原页复核具体机构。不要把「已匹配」说成「所有学者都已核验」。
- 论文库的 8,412 篇来自 536 个方向推荐学者的 ORCID 公开作品，覆盖 883 位学者、25 个领域，按 DOI / 标题去重；全部论文都有领域分类。它不是全部 18,296 位学者的完整发表清单，也不是全站检索。晚于快照年份（2026）的提前登记年份不计入。非方向推荐学者虽然能看到活跃度与 3 篇近期作品，但不会自动进入论文库，详情页会直接注明。
- 学者机构字段仍可能滞后：ORCID 修正只采用没有结束日期的任职记录，机构仍建议以 ORCID 原页复核。地区按院校所在机构库（OpenAlex 机构地理字段 + ROR）归档，18,296 位学者中 16,753 位已归档，1,543 位因机构地理字段缺失明确标为「地区待核验」，仍是离线快照，机构标注错误时会跟着错。
- 期刊推荐仍是 701 个 venue 与 536 个方向关键词 / 类目的字符串匹配，不是投稿难度或录取率预测。
- ORCID、ROR 都是离线快照（2026-11-18），不是实时查询；页面不会在打开时调用外部接口。
- 开场页右侧是原创塞莎特计算机 / AI 主题插画（由本机图像生成后做透明化处理，WebP 静态图），不是实时生成；工作台候选为示例展示；实际结果由本地离线索引生成，所有统计数字仍是离线数据，不是实时查询。
- Web 版不包含 53.8 万篇 arXiv 向量检索、PDF 下载、在线模型接入；这些属于桌面完整版。
