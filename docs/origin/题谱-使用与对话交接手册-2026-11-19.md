## 3. 日常使用：从方向到可执行任务

建议按下面五步使用，不需要先把所有页面填完。

1. **输入研究方向。** 在总览的方向输入框开始，或直接进入「选题工坊」；先确认方向识别与约束是否正确，再看候选。
2. **核对依据。** 结合「文献空白」「文献库」「素材库」检查已有工作、数据集、评测指标和基线；有需要再抓取「最新研究」。
3. **保存自己的候选。** 选中候选并存入「创新点库」，补充问题、机制、基线、数据、指标和停止条件。
4. **生成下一步研究清单。** 在「科研方法论」选择该课题，阅读对应方法并生成提示词或改进计划；生成提示词不等于已执行实验。
5. **安排具体工作。** 在「研究计划」添加阶段、截止日期与待办，关联选题；用「导师与院校」「期刊会议」辅助核对合作和投稿方向。

### 3.1 14 个页面做什么

| 页面 | 主要操作 | 必须理解的边界 |
| --- | --- | --- |
| 总览 | 方向输入、进入选题、查看研究计划摘要和本地统计 | 统计随本地数据变化，不是论文质量评分 |
| 选题工坊 | 识别方向、生成候选、查看详情、跨领域组合、存为创新点、生成交接提示词 | 候选与预筛分数只是线索，不是已证实的新颖性或可发表性 |
| 文献空白 | 分析本地材料中的方法、任务、问题组合，保存待核查方向 | 本地未覆盖不等于全球无人研究 |
| 最新研究 | 按方向检索 arXiv / OpenAlex / Europe PMC，查看全文信息、下载、AI 总结、存为已有工作 | 依赖外部服务；失败来源会提示；AI 总结需要人工核验 |
| 创新点库 | 新建、查看、结构诊断、生成审查提示词、复制摘要、删除 | 结构完整性不等于创新成立；删除会影响真实台账 |
| 科研方法论 | 七种方法切换、选择课题、生成单步提示词和完整改进计划 | 不代替研究判断和实验执行 |
| 导师与院校 | 按方向或姓名检索、查看公开索引信息、复制和导出 | 索引匹配不等于确认在职、招生或身份完全一致，需要官网核验 |
| 期刊会议 | 方向匹配、查看 venue 信息及来源入口 | 投稿范围、分区、截稿日期等应核验最新官方资料 |
| 素材库 | 搜索数据集，按大类或场景筛选，查看关联方向、指标、基线和来源 | 目录记录不代表数据已经下载；许可与可获取性需自行核对 |
| 文献库 | 本地 PDF 列表、分类与关键词筛选、语义 / 全文相关检索 | 依赖本机知识库和索引；标题提取及检索覆盖存在局限 |
| 方向图谱 | 选学科与领域、组合场景 / 方法 / 任务 / 模态、生成调研提示词、带入工坊或空白分析 | 组合相关度是辅助估计，不是文献空白结论 |
| 研究计划 | 添加阶段和待办、设置截止、勾选完成、关联选题、记录每周投入 | 不自动排期，不预测完成日期；所有安排由用户决定 |
| 个人画像 | 维护身份、目标、资源约束、状态和偏好 | 属于本机私人数据；硬条件会影响候选预筛 |
| 设置与数据 | 显示字号、主题、路径、检索词、模型连接等 | 保存会改真实配置；密钥只能通过受控本机配置流程处理 |

### 3.2 常用交互

- 侧栏切换页面；顶栏支持返回、前进和面包屑。
- `Alt + ←` / `Alt + →`：后退 / 前进。
- `Ctrl + K`：全局搜索。
- `Ctrl + Shift + L`：切换明暗主题。
- `Ctrl + =` / `Ctrl + -`：调整字号，也可以在设置中选择自动字号。
- 文字详情和长列表可滚动；研究计划的阶段区、待办区和详情区分别滚动。
- 长 AI 总结显示在独立滚动窗口中，避免把论文列表挤出屏幕。
- 提示词通常会复制到剪贴板，并在本机提示词目录存档；其中可能包含自己的选题信息，不要直接公开上传。

## 4. 本轮对话确定了什么

### 4.1 用户明确要求

本轮的核心要求是：

> 「整个的ui设计等内容，我需要你去学习网页版的设计方式，然后将整个的应用版大改。懂了吗」

已经明确的设计方向：

- 暖纸色画布、浅色卡片、棕色强调。
- 中文衬线页标题与清晰的区块层级。
- 紧凑列表、完整可访问的详情、随宽度换行的操作区域。
- 桌面保留原有真实功能，不把它替换成静态演示。
- 用户的大字号偏好要保留，不能靠缩小字号掩盖布局问题。
- 旧的中性灰 / 深蓝配色冻结已被本轮整体改造要求取代。
- 第三方参考截图只用于学习，不能发布或直接复制外部设计资源。
