## 3. 现在要发布什么（核心）

### 3.1 本轮修的问题：开场页空白

**现象**（用户截图）：开场页右半页几乎没有内容，只剩一个巨大的**椭圆**轨道环，插画与说明文字都不见了。

**根因链（已在本机逐条复现）**：

1. `competition/site/assets/intro.css` 里 `@media (max-width: 960px)` 的 `.intro-body { grid-template-columns: 1fr }` 会让窄而高的窗口（如 1189×1475）变成单列堆叠，插画被推到视口下方 —— 右半边只剩轨道环。
2. 插画没参与布局时，`.intro-herald` 高度塌成 0，`.ih-dial` 的 `width: var(--dial, min(82%, 500px))` 退化成"容器宽"，`aspect-ratio: 1` 于是画出一个**不是圆的椭圆** —— 这正是用户截图里的那个形状。
3. 原逻辑要等 webp **解码完成**才给插画挂 `.is-ready`（默认 `opacity: 0`），慢网 / 冷缓存下右栏会空好几秒。

### 3.2 三处代码改动（已改，源与 `dist/` 已同步，MD5 一致）

**文件 A：`competition/site/assets/intro.css`**

- 新增断点 `@media (min-width: 1121px) and (min-height: 1242px)`：窗口够宽、又很高的竖屏时改回左右双栏（`minmax(0,1fr) minmax(0,1.02fr)`，`gap:46px`），不再硬堆叠。
- 同一断点里把正文上移：`padding: clamp(16px,3vh,34px) 0 clamp(64px,13vh,190px)`，避免标题被压到窗口中线以下、上方空出五六百像素。
- `.ih-art` 增加 `min-height: clamp(240px, 40vh, 320px)`：图片没到时也先占住位置，右栏不会塌。
- `.ih-art` 改为 `load` 事件即淡入（`transition: opacity 300ms`），不再等解码。
- **明确撤回**一次失败尝试：给 `.intro-herald` 加 `aspect-ratio: 1024 / 1280` 的"画幅兜底"，实测会把首屏撑出滚动条、插图被挤成一条细缝（1000×1000 与 1600×1200 均复现）。CSS 里有注释说明为什么不能用，**不要再加回去**。

**文件 B：`competition/site/index.html`**

- `<img class="ih-art">` 增加 `id="ihArt"`。
- 新增一段内联脚本（在 `<script type="module" src="assets/app.js">` 之前）：量取插图栏实际宽高，写入 `--ih-h / --ih-w / --dial`；`load` 后经 `requestAnimationFrame` 双帧（外加 120ms 定时器兜底）再挂 `.is-ready`；解码失败则 `art.hidden = true` 整块收起，不留空洞；挂 `ResizeObserver` + `resize` / `orientationchange`。

**文件 C：`competition/site/dist/`** —— 上述两文件的同步副本（`dist/` 被 `.gitignore` 排除，不入库）。

## 6. 交接须知：踩过的坑

### 6.1 Tkinter / 桌面端

- **`winfo_ismapped()` 不能用来判断"控件是否还在布局中"**。窗口尚未映射时它返回 0，即使控件确实 pack 着。一律用 `winfo_manager()`。
- `T.Btn` 是 Label 子类（`app_theme.py:1349`），不能 `config(command=...)`，要用 `set_command()`；禁用态下点击与 `invoke()` 都不得执行。
- `page_venue.py` 的 `_venue_card(self, parent, v, idx)` 形参是 `v` 不是 `name` —— 曾因此触发 `UnboundLocalError`。
- 改共享卡片 / 滚动 / 换行组件后必须复测其他页面。

### 6.2 网页与静态站

- 站点按 `?v=` 与 `#/route` 组织；开场页动画从 `opacity:0` 起（见 3.5）。
- `web_fetch` 抓线上首页能看到正文数字，说明页面内容在禁用 JS 的环境里也能读到 —— 但截图与交互验证仍需真浏览器。

### 6.3 测试与隔离

- 桌面 GUI 测试逐个运行，不要同时开多个测试窗口；用户正在用真实应用时先协调时间。
- 相同尺寸或前缀的截图会覆盖同名验收图，需要留证据时先另存。
