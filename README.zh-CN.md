## 它是什么

题谱是一个**完全跑在你自己电脑上**的科研选题工作台，面向中国高校的本科生、硕士生和低年级博士生。

输入一个研究方向，它依次给你：方向识别 → 18 条带独立论证的候选 → 9 项结构体检 → arXiv 全库查重 → 文献空白矩阵 → 可联系的学者 → 可投的期刊会议 → 七套把它落成计划的方法。

它不替你决定做哪条题，也不给选题打分数。它只保证：在你决定之前，该看的材料你都已经看到了。

## 核心要点

| 要点 | 一句话 |
| --- | --- |
| 三个零 | 零云端、零额外依赖、零 API 费用；53.8 万篇 arXiv 查重在本机完成 |
| 没有分数 | 旧版打分被一段词堆骗到 77 分，已彻底删除，改为 9 项结构清单 |
| 十二个页面 | 一个页面只回答一个问题，从「现在该做什么」到「密钥放哪」 |
| 七套方法论 | 每个方法都有强制产出格式和「最容易骗自己的地方」 |
| 536 / 701 / 21,847 | 536 个研究方向、701 个期刊会议、21,847 位学者，口径写在主文档里 |
| 已知限制 18 条 | 全部实测过，逐条列在主文档的「已知限制」表里 |
